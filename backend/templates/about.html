A Deep Transfer Learning Framework for Pneumonia Detection

This project presents an automated system for pneumonia detection using chest X-ray images, classifying cases into Normal, Bacterial Pneumonia, and Viral Pneumonia.

Dataset

A refined version of the Chest X-Ray Pneumonia dataset was used, where pneumonia cases were separated based on their cause.

Models Evaluated
  • VGG16
  • VGG19
  • ResNet50
  • ResNet101
  • DenseNet121
Best Performing Model

DenseNet121 achieved the highest accuracy of 93% and was selected for deployment.

This system is intended strictly for academic and research purposes.
